# 🏭 Predictive Maintenance & Risk Intelligence System

## Banaras Locomotive Works - Internship Project

### 📋 Overview
This project implements a modern predictive maintenance system using ensemble machine learning and anomaly detection techniques to predict machine failures and recommend proactive maintenance actions.

### 🧠 Key Features
- **Random Forest** for failure probability prediction
- **Isolation Forest** for anomaly detection
- **Hybrid Risk Engine** combining ML predictions with domain logic
- **Feature Importance Analysis** to understand failure drivers
- **Interactive Dashboard** with real-time insights
- **Auto-generated Reports** for maintenance planning
